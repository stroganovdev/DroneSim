# Переключение FPV-пульта и Xbox

В Play: Tab → «Ввод» → «Источник управления» → FPV-пульт / HID либо Xbox / геймпад → «Применить и продолжить». Выбор сохраняется в DroneFlightSettings.sav вместе с индивидуальной раскладкой. Tab/«Продолжить» отменяет черновик. View (левая маленькая кнопка Xbox) также открывает/закрывает паузу; основная клавиатура и мышь доступны для меню. Полная навигация всего меню только геймпадом отдельно не проверена.

## Xbox по умолчанию

- Левый стик по вертикали: газ. Внизу 0%, в центре 50%, вверху 100%, как на RadioMaster Mode 2.
- Левый стик по горизонтали: поворот (yaw).
- Правый стик по горизонтали: крен (roll).
- Правый стик по вертикали: тангаж (pitch).
- Мёртвая зона 0.12; вне неё значение плавно масштабируется до полного диапазона.

Во вкладке ввода можно назначить четыре команды на стандартные оси обоих стиков и курков, менять мёртвую зону 0–0.4 и инверсию тангажа. Газ на стике использует полный диапазон [-1,1]. Пружина Xbox возвращает стик к 50% газа: для нулевого газа держите его внизу. Мёртвая зона применяется к вращению; газ на стике линейный. При ручном назначении курка сохраняется диапазон 0–100% с нулём при отпускании. Режим накопления газа не реализован. Дублирование назначений допускается намеренно.

«Сброс раскладки Xbox» меняет только черновик раскладки. «Сброс Meteor75» сохраняет выбор устройства и раскладку, сбрасывая параметры полёта/коптера/камеры. Для применения обоих сбросов нужна кнопка «Применить».

## Изоляция и подключение

Команды полёта берутся строго из выбранного источника. Наличие второго устройства не меняет выбор и не подмешивает оси. При отсутствии выбранного источника газ/вращения обнуляются; автоматического переключения на другой тип нет. При смене источника и после отключения/возврата нужно опустить газ и отпустить вращательные оси. Сначала система должна получить данные устройства; если Xbox ещё не послал их, пошевелите стики, затем опустите левый до упора вниз, остальные оси оставьте в центре. Это предотвращает применение удерживаемого газа сразу после переключения.

Xbox работает через стандартные Gamepad_* события Unreal/Slate, а не через ручную HID-калибровку. USB и Bluetooth используют одну раскладку. При потере фокуса Xbox-кэш сбрасывается; возврат требует нового нейтрального состояния. Если подключено несколько стандартных геймпадов, используется один с минимальным текущим InputDeviceId; выбора конкретного Xbox-слота в меню пока нет.

HID-пульт использует прежний DroneInputMappings.json. При нескольких калиброванных HID выбирается один с минимальным текущим ID: разные команды не читаются с разных пультов. Профиль Pocket, калибровка и исходные ассеты не изменены этим этапом.

## Как расширять

Публичный контракт: Plugins/DroneSimulator/Source/DroneSimulatorInput/Public/DroneControlSource.h. Новый адаптер реализует IDroneControlSource (уникальный FName, подпись, доступность, нормализованное чтение осей; при необходимости Tick/Reset) и регистрируется через UDroneInputSubsystem::RegisterControlSource до применения настроек игрока. Меню получает список из реестра автоматически; физика, PID и DroneMovementComponent не меняются при добавлении адаптера. Повторный ID отклоняется. Недоступный зарегистрированный источник не заменяется другим; отсутствующий после загрузки сохранённого профиля адаптер отключает полётный ввод до выбора доступного.

Контракт осей: yaw/pitch/roll в [-1,1]; throttle в [0,1] либо [-1,1] согласно EThrottleCalibrationSpace. Ноль тяги в signed-формате равен -1. Значения на выходе маршрутизатора ограничиваются диапазоном; NaN/Inf дают безопасный ноль. Для настроек нового адаптера добавляются отдельная структура/виджет или строки в существующий UI; текущая панель раскладки специфична для Xbox.

## Проверки

DroneSimTest.Input.SourceIsolation: два независимых тестовых адаптера, отсутствие смешивания/fallback, удерживаемый газ при выборе, отключение и повторный нейтральный вход. DroneSimTest.Input.GamepadNormalization: курок, полные диапазоны, дрейф, NaN и проверка конфигурации. Вместе с DroneSimTest.Settings.Validation: 3 passed, 0 failed (Saved/Automation/XboxInputFinal/index.json).

Scripts/TestControlSourcesPIE.py запускать с -UserDir=E:/UnrealProjects/DroneGame/DroneSimTest/Saved/QualityXboxPIE. Проверены отмена черновика, применение без нового Pawn, независимый сброс Meteor, сохранение переназначенного газа/инверсии/deadzone в новом GameInstance и возврат на Radio. Отчёт Saved/ControlSourcesPIE.json: success=true. Тестовая запись настроек изолирована; автоматические FlightRecord-ассеты тестов перемещены в Backup/XboxInput_20261027/GeneratedRecords.

Проверки реального Xbox и packaged build фиксируются отдельным результатом после их выполнения; тестовые адаптеры не доказывают работу физического устройства.

Совместимость старого сохранения подтверждена отдельным запуском: Saved/XboxLegacySave.json, success=true; исходный файл пользователя сохранил прежние байты. В новом packaged build выбран Gamepad, стандартная RT-раскладка загрузилась из тестового SaveGame. Физический полный RT/полёт пока ожидают участия пользователя.
