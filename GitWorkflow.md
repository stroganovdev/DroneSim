# Git: локальная история DroneSimTest

Основная ветка: main. Ассеты Unreal хранятся через Git LFS.
Первый коммит фиксирует существующий проект; его успешная Editor-сборка не заменяет игровые тесты.

Перед работой: git status --short
После задачи: проверить diff, выполнить сборку Scripts/BuildDroneSimTestEditor.ps1 и проверки затронутой функции, затем добавить только относящиеся к задаче файлы и создать коммит.
Не отменять чужие изменения и не выполнять reset --hard без отдельного поручения.

В истории: Source, Content (включая World Partition external actors), Config, Plugins, Scripts, документация и стандартный профиль пульта DroneInputMappings.json.
Исключены: Binaries, Intermediate, Saved (личные сохранения и калибровка), DerivedDataCache, Backup и файлы IDE.
Локальные исключённые файлы Git не восстанавливает; при необходимости сохраняйте их отдельно.

На другом компьютере перед получением ассетов нужен Git LFS: git lfs install; git lfs pull.
Удалённый репозиторий пока не настроен. Локальная история на том же диске не является резервной копией на случай отказа диска.
